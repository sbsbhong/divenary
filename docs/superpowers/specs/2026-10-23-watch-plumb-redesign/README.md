# 워치 리디자인 "Plumb · 측심" 설계 묶음

2026-10-22~23에 소유자 요청("애플 같은 느낌, 애니메이션, 감동적으로 예쁜 워치 앱")으로 만든 워치 앱 리디자인 설계다. 리서치(현재 화면 비평, 다이버 UX, 애플 watchOS 디자인 언어), 세 가지 방향 비교와 두 관점 심사를 거쳐 'Plumb · 측심' 방향을 기반으로 정했고, Codex 검수와 소유자 피드백을 반영해 디자인 캔버스로 확정했다.

- 디자인 캔버스(시안 52장, 인터랙티브 프로토타입 포함, 비공개): https://claude.ai/artifact/4esQ3ZLeVwfSufpymFiuow
- 구현 계획: `docs/superpowers/plans/2026-10-23-watch-plumb-redesign.md`

## 문서와 우선순위

뒤의 문서가 앞의 문서보다 우선한다.

1. `spec.md` — 최초 종합 설계서. 토큰(§B), 컴포넌트(§C), 모션(§D), 목업 데이터(§E), 화면별 배치(§F), 규칙 대조(§G). 크기는 `pt/px`로 적었고 캔버스 목업 기준이라 1 pt = 2 CSS px다. §F의 CSS 좌표는 캔버스용이며, 구현에서는 pt 값과 컴포넌트 구조를 따른다.
2. `COPY-OVERRIDES.md` — 위키와 출시 문구 대조 뒤 확정한 화면 문구(C1–C15).
3. `DECISIONS.md` — 디자인 리드 결정(D1–D19). 특히 다음이 spec을 바꾼다.
   - D1 수심에 고정된 게이지 그라데이션 기본 적용
   - D10 시스템 크롬 실측값(시계, 큰 제목, 콘텐츠 시작, 툴바 원)
   - D11 요약 순서(최대 수심 → 다이빙 시간 → 그래프 → 워치에 저장됨 → 하단 안내 칩)
   - D12–D14 모션: 물속 자동 변화는 크로스페이드만, 다이버가 넘길 때만 이동
   - D15 소유자가 제안 P2–P7, P12, P13을 모두 채택
   - D16 실제 로고 윤곽만 사용(`LOGO.md`)
   - D17 애플 '수심' 앱을 강하게 연상시키는 조합 제거(물결 아이콘, 저장 순간 "수심" 제목, 크라운+수심 데모 문장)
   - D18 P3 범위 전환은 유일한 자동 이동 예외
   - D19 다이버 그림 아이콘 시도는 되돌림. 프리다이빙=모노핀, 스쿠버=탱크 유지
4. `LOGO.md` — 실제 앱 로고에서 추출한 가오리 벡터 경로. 앱 안의 가오리는 이것만 쓴다.

## 구현에서 바뀌지 않는 것

- 기록 판단 로직(`RecordingPageModel`), 햅틱 5종, 1Hz 갱신, 비인증 경계, 40 m 지원 범위와 범위 밖 처리, 권장 스탑 판단은 그대로다. 이번 작업은 표현과 문구만 바꾼다.
- 실제 물속 센서 동작과 동작 버튼 연결은 실기기 확인 대상이다.
