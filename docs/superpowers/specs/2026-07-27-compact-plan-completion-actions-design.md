# Compact Plan Completion Actions Design

Date: 2026-07-27
Status: Approved

## 배경

계획을 완료하면 표시되는 로그 작성 프롬프트의 두 액션은 동일한 가로폭을
유지해야 하지만, 현재 최소 48pt 높이와 넓은 패딩 때문에 프롬프트 안에서
과도하게 커 보인다.

## 디자인

- `나중에`와 `계획에서 로그 작성` 버튼은 현재처럼 한 행에서 같은 너비를 유지한다.
- 이 프롬프트에서만 버튼 최소 높이를 Apple 터치 영역 기준인 44pt로 줄인다.
- 수직 패딩은 12pt에서 8pt로, 수평 패딩은 20pt에서 16pt로 줄인다.
- 글자 크기, 버튼 순서, primary/secondary 색상과 동작은 변경하지 않는다.
- 공용 `InstrumentButton` 기본값과 다른 화면의 버튼은 변경하지 않는다.

## 검증

- 계획 완료 프롬프트의 두 버튼 모두 compact class를 사용한다.
- 공용 버튼의 기본 48pt 스타일은 그대로 유지된다.
- 계획 완료, 나중에 닫기, 로그 작성 callback 동작은 기존 테스트를 통과한다.
- 모바일 TypeScript 검사를 통과한다.

## 제외 범위

- 프롬프트 카드 구조, 문구, 애니메이션 변경
- 계획 또는 로그 데이터 흐름 변경
- 다른 화면의 버튼 크기 변경
