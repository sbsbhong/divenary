# Watch callback, retry, re-entry, navigation hardening

Apple의 현재 온라인 `CMWaterSubmersionManagerDelegate` 문서는 모든 delegate method가 anonymous background queue에서 호출되며 MainActor 객체로 전달하라고 명시한다. 반면 설치된 watchOS 26.5 SDK의 `CMWaterSubmersionManager.h` 18-22행은 method가 main queue에서 호출된다고 적는다. 구현은 두 환경에서 모두 안전한 더 엄격한 온라인 계약을 따른다. delegate callback executor에서 event state/date, depth, pressure, temperature, depth state, maximum authorized depth, error text를 Sendable scalar snapshot으로 만든 뒤 `Task { @MainActor ... }`로 전달한다. Core Motion manager, event, measurement, temperature object와 `Error` existential은 actor hop을 넘지 않으며, production manager owner는 계속 `WaterSubmersionCoordinator` 하나다.

1Hz sample이 pending sidecar 생성 전에 실패할 수 있으므로 `DiveSessionRecorder`는 canonical in-memory sample append와 별도로 unconfirmed sample을 ordered `ArraySlice`에 보관한다. later sample과 final flush는 항상 oldest unconfirmed sample부터 처리하고, `popFirst()`로 성공한 head를 O(1)에 제거한다. queue 전체가 비었을 때만 persistence error를 지운다. `DiveProfileArtifactStore`가 pending append를 복구한 경우 decoded `DepthSample` value를 retry sample과 비교해 JSON object key order와 무관하게 이미 기록된 sample을 중복 append하지 않는다.

manual runtime acquisition은 명시적 Bool 결과를 반환한다. false는 controller에 active adapter가 남아 있다는 뜻이므로 coordinator는 먼저 시작한 recorder를 정리하고, `awaitingRuntimeInvalidation`으로 전환한 뒤 runtime invalidation을 요청한다. 이 상태에서는 dismiss, manual start, Action Button start를 모두 거부한다. runtime controller는 matching adapter를 event 발행 전에 지우며, callback 뒤에만 error가 dismissible해진다. recorder cleanup 실패는 error dismissal에서 다시 시도한다. adopted setup failure도 같은 invalidation gate를 사용하고 stale callback은 replacement recording을 finalize하지 않는다.

Demo/debug lifecycle은 recording, summary, unresolved cleanup 동안 system back을 숨긴다. summary는 Save 또는 Discard 성공 뒤에만 completed가 되며, 실패는 visible retry state를 유지한다. external real flow가 가린 recording/summary cleanup도 성공 뒤 재등장할 때만 dismiss하고 실패하면 summary 또는 cleanup retry로 돌아온다. Digital Crown depth simulation과 surface-gated touch ending은 그대로다.

이 변경은 callback serialization, local recording durability, runtime re-entry, navigation cleanup만 다룬다. physical pressure/depth/temperature delivery, signed entitlement/profile, 실제 `When Submerged`, Water Lock/Crown, Action Button hardware behavior, watchOS out-of-water timeout은 검증하지 않았다. local 3m auto-start, app-owned 10-minute timer, real touch ending은 추가하지 않았으며, 앱은 감압 또는 생명-critical 판단을 제공하지 않는 비인증 기록 companion이다.
